01 — THE PROBLEM

Warehouse automation should not become fragile as it grows.

Centralized fleet managers create a single point of failure. Server outages can stop the whole fleet, Wi-Fi dead zones interrupt coordination, and central arbitration turns intersections into stop-and-wait queues as robot count rises.

02 — DISTRIBUTED COORDINATION

Local intelligence.
Collective motion.

Each robot is an intelligent node in a self-healing peer-to-peer mesh. New robots add local redundancy and communication paths rather than adding central-server load.

01

GNN multi-link coordination

A graph neural network represents AMRs as connected nodes, captures spatial and motion relationships, and identifies likely interactions before they turn into conflicts.

02

Conflict-aware navigation

Conflict-Based Search detects path conflicts and creates constraints for collision-free rerouting. DM³ extends this with decentralized multi-robot semantic navigation.

03

Shared local awareness

Swarm-SLAM builds collaborative route awareness across the fleet, while peer-to-peer intent sharing maintains distributed task state through link or node loss.

03 — THE EDGE-AI LOOP

Sense, understand,
coordinate, act.

The control cycle is continuous and local. Robots combine their own sensor data with messages from nearby peers to make a safe action at the edge.

01

Sense & estimate

2D LiDAR maps the environment; IMU and wheel encoders estimate orientation, velocity, position, and distance.

02

Plan & negotiate

Sensor fusion, GNN coordination, CBS, and Swarm-SLAM evaluate conflicts, priorities, and feasible local routes.

03

Execute locally

On-device AI turns the local state into motion actions, with distributed allocation and fleet-level intent sharing.

09 — FAQ

Useful answers,
without the hype.

What replaces the central fleet server?

There is no single replacement. Each robot combines local sensing, on-device decision logic, GNN-based coordination, and messages from nearby peers to take safe local actions.

How are conflicts avoided between robots?

Conflict-Based Search detects collisions between paths, while graph-based coordination models nearby interactions and decentralized navigation produces collision-free local alternatives.

What happens when communication drops?

Robots retain their local state and continue their current task safely. When mesh links return, the peer-to-peer fleet state can re-synchronize without needing a central restart.

What hardware does the approach use?

The proposed edge stack uses a Jetson Nano or Raspberry Pi 4, 2D LiDAR, IMU, wheel encoders, Wi-Fi mesh networking, and ROS 2 Humble.
